# Rejected experiments

## R16-A

R16-A was rejected and rolled back. Its replay-budget phase split did not
replace the accepted R15-B baseline. No R16-A patch or process evidence is
included in this branch.

## R16-C

R16-C was rejected and rolled back after a first-order runtime regression. The
static gates passed, but the control smoke produced no validated localization:
strict attempts ended with no fresh RGB, and a later outer envelope expired in
transit. Formal Run 1 and Run 2 were not opened. No dual-envelope budget patch,
inverse patch, snapshot, raw ledger, or runtime evidence is included in Git.

The upload therefore retains the accepted R15-B behavior and does not claim
R16-A or R16-C performance. Formal WM2-A remains an evidence view, not runtime
control authority.
