The archive manifest records every member path, byte size, and SHA-256. It
contains source pre/post identity evidence, raw test output, selected R15-B
formal evidence, rejected R16-A/R16-C evidence, rollback records, and audit
working files. Runtime logs, seed ledgers, screenshots, videos, snapshots,
inverse patches, container state, and machine-specific paths must be consulted
through that archive and are not part of this branch.

The repository documents only this archive filename and digest. No local
evidence path is portable or authoritative.
